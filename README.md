# 🛒 Zepto E-commerce Data Analysis

## 📌 Project Overview

An end-to-end E-commerce Data Analytics project based on Zepto product data.

The project analyzes product pricing, discounts, inventory availability, stock-outs, category performance, and pricing patterns using **MySQL and Power BI**.

## 🛠️ Tools & Technologies

* MySQL
* Power BI
* SQL
* Excel/CSV
* DAX
* Power Query

## 📊 Dataset

The dataset contains product-level information including:

* Product name
* Category
* MRP
* Selling price
* Discount
* Discount percentage
* Available quantity
* Out-of-stock status
* Product weight
* Price per gram

## 🔍 SQL Analysis

The SQL analysis includes:

* Database and table creation
* Data cleaning and validation
* Handling missing values
* Price and discount analysis
* Category-level analysis
* Inventory analysis
* Stock-out analysis
* CTE-based analysis
* CASE statements
* Window functions
* Business insight generation

## 📈 Power BI Dashboard

The Power BI dashboard contains three pages:

### Page 1 — Business Overview

Key KPIs:

* Total Products
* Total Categories
* Average Selling Price
* Average Discount %
* Out-of-Stock Products
* Stock Availability %

### Page 2 — Pricing & Inventory Analysis

Visualizations include:

* MRP vs Selling Price
* Discount analysis
* Price distribution
* Inventory availability
* Stock-out analysis
* Category-wise inventory

### Page 3 — Category & Product Analysis

Visualizations include:

* Category-wise product count
* Category-wise average price
* Category-wise discount %
* Top products
* Inventory risk analysis
* Product-level performance

## 💡 Key Business Questions

This project answers questions such as:

1. Which categories have the highest number of products?
2. Which categories offer the highest discounts?
3. Which products are out of stock?
4. Which categories have the highest stock-out rate?
5. What is the average selling price by category?
6. Which products have the highest discount amount?
7. Which products have low inventory?
8. Which categories require inventory replenishment?
9. How does selling price vary across categories?
10. Which products provide potential pricing opportunities?

## 🎯 Business Insights

The analysis helps identify:

* High-discount categories
* Low-stock products
* Stock-out risks
* Pricing opportunities
* Category-level performance
* Inventory replenishment priorities
